# Pourquoi Python ?

Python est un langage interprété, multiplateforme et polyvalent. Sa syntaxe lisible en fait un excellent choix pour l'apprentissage, l'automatisation, le web, la data science et l'intelligence artificielle.

![Écosystème supervisé et non-supervisé de l'IA](/lms/supervised-unsupervised.svg)

- **Lisibilité** : une syntaxe concise et proche du langage naturel.
- **Écosystème** : des bibliothèques pour presque tous les domaines.
- **Communauté** : une documentation abondante et une communauté active.

## Points clés

- Python privilégie la lisibilité
- Il convient aussi bien aux débutants qu'aux projets avancés

---

# Premier programme

Créez un fichier `bonjour.py`, puis exécutez-le avec `python bonjour.py`.

```python
nom = input("Quel est votre nom ? " )
print(f"Bonjour {nom} !")
```

### Bonjour interactif

```python
nom = input("Votre nom : " )
print(f"Bienvenue, {nom} !")
```

Le programme lit une valeur puis l'insère dans une chaîne formatée.

## Points clés

- Un script Python utilise l'extension .py
- La fonction print affiche une valeur
